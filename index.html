Guest meeting room guide

Share Your Screen

Present from your Windows laptop or Mac using the purple Logitech Swytch USB-A / USB-C connector.

1. Install DisplayLink

First visit only. Choose your laptop's operating system.

WindowsGet official driver ↗ MacGet official app ↗

These buttons open the official Synaptics download pages. On that page, select the latest compatible release and follow the prompts. No installer is stored on this website.

2. Connect and present

  1. Install the downloaded DisplayLink software. Restart if prompted.
  2. Connect the purple Logitech Swytch USB-A or USB-C cable to your laptop.
  3. Windows: Press Windows + P and select Duplicate or Extend.
  4. Mac: Open DisplayLink Manager and allow Screen Recording / Screen & System Audio Recording permissions if requested. Keep DisplayLink Manager running.
Installation blocked by company security?

Some work laptops require administrator permission to install drivers. Ask your IT team or the meeting organizer for another way to present. This webpage cannot bypass your company's security settings.

Driver software is provided by Synaptics / DisplayLink. This page is a meeting-room quick-start guide, not an official Synaptics website.
